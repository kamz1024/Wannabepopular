# wannabepopular.com

Static site for wannabepopular, hosted on GitHub Pages with Cloudflare DNS.

## Files
- `index.html` — the full single-page site (all sections, hash routing)
- `CNAME` — tells GitHub Pages the custom domain is wannabepopular.com

## Deploy
Push to a public repo, enable Pages (Settings → Pages → deploy from `main` / root),
set the custom domain, then point Cloudflare DNS at GitHub. See chat for full steps.
